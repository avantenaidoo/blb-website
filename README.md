# BLB Digital Marketing Website

A responsive business website developed for **BLB Digital Marketing**, showcasing its digital marketing and website development services.

The project focuses on clean design, reusable JavaScript components, responsive layouts and maintainable code.

## Live Website

[**Visit BLB Digital Marketing**](https://blbdigitalmarketing.onrender.com)

## Features

- Responsive layout for desktop, tablet and mobile devices.
- Modular JavaScript architecture with reusable website components.
- Hero section introducing the business.
- Services section with manually navigated image slides.
- About section presenting the business and its services.
- Contact section with direct email links for digital marketing and website development enquiries.
- Responsive navigation with a mobile menu.
- Accessible navigation and interactive elements.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES Modules)
- Vite
- Vitest

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/avantenaidoo/blb-website.git
   ```

2. Navigate into the project directory:

   ```bash
   cd blb-website
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

### Run Locally

Start the Vite development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

## Testing

The project uses Vitest for automated testing.

Run the test suite using the configured npm test script.

## Production Build

Create an optimised production build:

```bash
npm run build
```
